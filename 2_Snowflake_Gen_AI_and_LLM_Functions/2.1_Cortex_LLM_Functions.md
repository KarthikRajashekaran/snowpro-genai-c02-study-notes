# 2.1 AISQL Function Catalog (General + Task-Specific)

**AISQL** is Snowflake Cortex's suite of SQL-callable AI functions for running generative and analytical AI over text, documents, images and audio — directly in a query, with no infrastructure to manage. The C02 exam is organized around the **`AI_*`** names. This page is the catalog: for each function you get its **purpose**, a realistic **SQL example**, and its **key parameters**.

## Naming: AI_* vs SNOWFLAKE.CORTEX.* vs legacy aliases

- **`AI_*`** — current, preferred names (`AI_COMPLETE`, `AI_CLASSIFY`, `AI_EMBED`, …). **Use these.**
- **`SNOWFLAKE.CORTEX.*`** — the schema the functions live in. `AI_COMPLETE` is callable as `SNOWFLAKE.CORTEX.AI_COMPLETE` or, unqualified, as `AI_COMPLETE` once the schema is on your path.
- **Legacy aliases** — older names that still run: `COMPLETE` → `AI_COMPLETE`, `CLASSIFY_TEXT` → `AI_CLASSIFY`, `SENTIMENT` → `AI_SENTIMENT`, `TRANSLATE` → `AI_TRANSLATE`, `PARSE_DOCUMENT` → `AI_PARSE_DOCUMENT`, `EMBED_TEXT_768/1024` → `AI_EMBED`.

| Group | Functions |
|-------|-----------|
| **General** | `AI_COMPLETE` (+ structured outputs) |
| **Task-specific** | `AI_CLASSIFY`, `AI_FILTER`, `AI_AGG`, `AI_SUMMARIZE_AGG`, `AI_SIMILARITY`, `AI_SENTIMENT`, `AI_EXTRACT`, `AI_PARSE_DOCUMENT`, `AI_TRANSLATE`, `AI_EMBED`, `AI_TRANSCRIBE`, `AI_REDACT`, `SUMMARIZE` |
| **Vector** | see [2.3](./2.3_Vector_and_Helper_Functions.md) |
| **Helper** | `AI_COUNT_TOKENS`, `TRY_COMPLETE`, `SPLIT_TEXT_*`, `TO_FILE`, `PROMPT` — see [2.3](./2.3_Vector_and_Helper_Functions.md) |

> `AI_COMPLETE` gets its own deep dive in [2.2](./2.2_Cortex_LLM_Complete_Functions.md) (structured outputs, options, multimodal). This page focuses on the task-specific catalog.

## General

### AI_COMPLETE()
**Purpose:** General-purpose text (and multimodal) generation / completion — the workhorse. Replaces `COMPLETE`. Supports **structured outputs** via a JSON schema.

```sql
-- Simplest form: model, prompt
SELECT AI_COMPLETE('claude-3-5-sonnet', 'Explain vector embeddings in one sentence.');

-- With model parameters
SELECT AI_COMPLETE(
    model  => 'llama3.1-70b',
    prompt => 'Draft a 2-line apology to a customer whose order was late.',
    model_parameters => {'temperature': 0.2, 'max_tokens': 120}
);
```

**Key parameters:** `model`, `prompt` (string or an array of `messages` / a `PROMPT()` object for multimodal), `model_parameters` (`temperature`, `max_tokens`, `top_p`), `response_format` (JSON schema → structured output), `show_details` (returns token usage/metadata). Full treatment in [2.2](./2.2_Cortex_LLM_Complete_Functions.md).

## Task-Specific Functions

### AI_CLASSIFY()
**Purpose:** Classify **text or images** into your categories; supports single-label and **multi-label** output. Replaces `CLASSIFY_TEXT`.

```sql
-- Single-label
SELECT AI_CLASSIFY('One day I will see the world', ['travel','cooking','reading']) AS label;

-- Multi-label + task description + category descriptions
SELECT AI_CLASSIFY(
    review_text,
    [ {'label':'food','description':'food quality & taste'},
      {'label':'service','description':'staff & wait time'},
      {'label':'price','description':'value for money'} ],
    {'output_mode':'multi', 'task_description':'Tag restaurant review aspects'}
) AS aspects
FROM reviews;
```

**Key parameters:** `input` (STRING or FILE image), `categories` (ARRAY of labels or `{label,description}` objects, up to 500), `config` (`output_mode` `'single'`/`'multi'`, `task_description`, `examples` for few-shot). Returns an object with a `labels` array.

### AI_FILTER()
**Purpose:** Evaluate a natural-language condition and return **TRUE/FALSE** — use it in `WHERE`, joins, and inside `AI_AGG`/`GROUP BY` to keep only rows that match a semantic predicate.

```sql
-- Keep only reviews that complain about shipping
SELECT * FROM reviews
WHERE AI_FILTER(PROMPT('Is this review about slow or damaged shipping? {0}', review_text));

-- Semantic join: match tickets to the FAQ they answer
SELECT t.id, f.faq_id
FROM tickets t JOIN faq f
  ON AI_FILTER(PROMPT('Does this FAQ answer the ticket?\nFAQ: {0}\nTicket: {1}', f.body, t.body));
```

**Key parameters:** a single predicate argument — either a string condition or a `PROMPT()` template with column placeholders. Returns BOOLEAN.

### AI_AGG()
**Purpose:** **Aggregate** a text column across many rows into one answer, following a natural-language instruction — without the per-call context-window limit of stuffing rows into one prompt. Use it like `MAX`/`LISTAGG` but AI-driven.

```sql
SELECT
    product_id,
    AI_AGG(review_text, 'Summarize the top 3 recurring complaints across these reviews') AS themes
FROM reviews
GROUP BY product_id;
```

**Key parameters:** `expr` (text column to aggregate), `task_description` (instruction). It is an aggregate function → pairs with `GROUP BY`.

### AI_SUMMARIZE_AGG()
**Purpose:** Aggregate **summary** across many rows — a summarization-specialized `AI_AGG`, again free of single-prompt context limits.

```sql
SELECT region, AI_SUMMARIZE_AGG(feedback) AS regional_summary
FROM survey_responses
GROUP BY region;
```

**Key parameters:** `expr` (text column). Aggregate function; use with `GROUP BY`.

### AI_SIMILARITY()
**Purpose:** Semantic **similarity between two inputs** (text or images). Embeds both internally and returns a score — no manual `AI_EMBED` + `VECTOR_COSINE_SIMILARITY` needed for one-off comparisons.

```sql
SELECT AI_SIMILARITY('AI is transforming business', 'Machine learning changes companies') AS score;

-- Rank FAQs against a question
SELECT faq_id, AI_SIMILARITY(:question, faq_text) AS rel
FROM faq ORDER BY rel DESC LIMIT 5;
```

**Key parameters:** `input1`, `input2`, optional `config` (embedding model, `metric`). Returns a FLOAT (cosine by default, roughly -1..1). For large-scale search, embed once with `AI_EMBED` and use vector functions instead (see [2.3](./2.3_Vector_and_Helper_Functions.md)).

### AI_SENTIMENT()
**Purpose:** Sentiment analysis. Beyond an overall score it can return **entity/category-level** sentiment (e.g. sentiment about "food" vs "service" in one review). Replaces `SENTIMENT`.

```sql
-- Overall sentiment
SELECT AI_SENTIMENT(review_text) AS sentiment FROM reviews;

-- Aspect-based sentiment for named categories
SELECT AI_SENTIMENT(review_text, ['food','service','price']) AS aspect_sentiment
FROM reviews;
```

**Key parameters:** `text`, optional `categories` (ARRAY of aspects). Returns an object with categories, each labeled `positive` / `negative` / `neutral` / `mixed`. (Legacy `SENTIMENT` returns a single FLOAT in -1..1.)

### AI_EXTRACT()
**Purpose:** **Extract** structured fields / answers from text or documents — pass the questions or field names you want and get back a structured result. Modern replacement for `EXTRACT_ANSWER` that also works on files.

```sql
SELECT AI_EXTRACT(
    text => contract_text,
    responseFormat => ['contract_value','effective_date','counterparty','termination_notice_days']
) AS fields
FROM contracts;
```

**Key parameters:** `text`/`file` (input, incl. a `TO_FILE()` document), `responseFormat` (list of fields, or question→key mapping). Returns an object keyed by your fields.

### AI_PARSE_DOCUMENT()
**Purpose:** Parse **PDFs and images** in a stage into text + layout — OCR and document-structure extraction. The front door for RAG over documents. Replaces `PARSE_DOCUMENT`.

```sql
SELECT AI_PARSE_DOCUMENT(
    TO_FILE('@docs_stage', 'msa_2026.pdf'),
    {'mode': 'LAYOUT'}          -- 'OCR' (raw text) or 'LAYOUT' (structure/tables/markdown)
) AS parsed;
```

**Key parameters:** `file` (a `TO_FILE()` reference to a staged doc), `options` — `mode` (`OCR` vs `LAYOUT`), `page_split`. Returns JSON with extracted content (LAYOUT preserves tables/headings, ideal for markdown-header chunking).

### AI_TRANSLATE()
**Purpose:** Translate text between languages. Replaces `TRANSLATE`.

```sql
-- Auto-detect source ('' ) → French
SELECT AI_TRANSLATE(review_text, '', 'fr') AS fr FROM reviews;

-- Explicit source → target
SELECT AI_TRANSLATE('Hello world', 'en', 'ja') AS ja;
```

**Key parameters:** `text`, `source_language` (`''` = auto-detect), `target_language` (ISO codes: `en`, `es`, `fr`, `de`, `ja`, `ko`, `zh`, …).

### AI_EMBED()
**Purpose:** Generate a **vector embedding** for text (or images) to power semantic search, clustering and RAG. Unified replacement for `EMBED_TEXT_768` / `EMBED_TEXT_1024`.

```sql
CREATE OR REPLACE TABLE doc_vectors AS
SELECT id, chunk,
       AI_EMBED('snowflake-arctic-embed-l-v2.0', chunk) AS embedding   -- returns VECTOR(FLOAT, n)
FROM doc_chunks;
```

**Key parameters:** `model` (e.g. `snowflake-arctic-embed-l-v2.0`, `snowflake-arctic-embed-m`, `voyage-multilingual-2`, `e5-base-v2`), `input`. **Match the embedding model at query time to the one used at index time**, and match the dimension to your `VECTOR(FLOAT, n)` column.

### AI_TRANSCRIBE()
**Purpose:** **Speech-to-text** — transcribe an audio file staged in Snowflake. Enables audio analytics (then classify, summarize, sentiment, etc.).

```sql
SELECT AI_TRANSCRIBE(TO_FILE('@calls_stage', 'call_001.mp3')) AS transcript;
```

**Key parameters:** `file` (audio via `TO_FILE()`), optional config (timestamps/speaker segmentation where supported). Returns text (often with segment metadata).

### AI_REDACT()
**Purpose:** **Redact PII / sensitive spans** (names, emails, phone numbers, card numbers) from text — a governance/privacy step in pipelines before storing or sharing model inputs/outputs.

```sql
SELECT AI_REDACT(chat_message) AS safe_message FROM support_chats;
```

**Key parameters:** `text`, optional entity types to target. Returns the text with sensitive spans masked.

### SUMMARIZE() / AI_SUMMARIZE_AGG()
**Purpose:** `SUMMARIZE(text)` condenses a **single** value; `AI_SUMMARIZE_AGG` condenses **many rows** (see above).

```sql
SELECT SUMMARIZE(article_body) AS tldr FROM articles;
```

**Key parameters:** `text`. Returns a summary string.

## Choosing the right function (quick guide)

| You want to… | Use |
|--------------|-----|
| Generate text / JSON / reason | `AI_COMPLETE` |
| Bucket rows into categories | `AI_CLASSIFY` |
| Keep rows matching a semantic rule | `AI_FILTER` |
| Reduce many rows → one insight | `AI_AGG` / `AI_SUMMARIZE_AGG` |
| Compare two texts | `AI_SIMILARITY` |
| Score sentiment (overall/aspect) | `AI_SENTIMENT` |
| Pull fields from text/docs | `AI_EXTRACT` |
| Turn a PDF/image into text | `AI_PARSE_DOCUMENT` |
| Translate | `AI_TRANSLATE` |
| Build vectors for search/RAG | `AI_EMBED` |
| Transcribe audio | `AI_TRANSCRIBE` |
| Mask PII | `AI_REDACT` |

   - A) `AI_SIMILARITY`  B) `AI_EMBED`  C) `VECTOR_NORMALIZE`  D) `PROMPT`
